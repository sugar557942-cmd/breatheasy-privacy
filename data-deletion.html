숨쉬다 - 데이터 삭제 안내

'숨쉬다(BreatheEasy)' 앱을 이용해 주셔서 감사합니다. 사용자의 개인정보 보호와 데이터 통제권을 위해, 데이터가 어디에 저장되고 어떻게 삭제되는지를 있는 그대로 안내해 드립니다.

앱 이름: 숨쉬다 (BreatheEasy)

개발자/운영자: 인사이트빌드(Insightbuild) · 서비스 브랜드 'GoodSoom'

고객 문의: insightbuild@daum.net

0. 사전 안내 — 데이터 저장 위치

본 앱은 사용자의 의료/생활 데이터를 가능한 한 외부 서버에 보관하지 않는 구조로 설계되었습니다.

  • 디바이스에 저장: 증상 기록, 복약 기록, 생활습관 기록, 약 정보, 위치(시·도·동네명), 알레르기 정보, 일별 환경 영향 지수 등 의료 관련 데이터는 사용자의 디바이스 내 저장소에 보관됩니다(메모·약 이름 등 민감 필드는 암호화). 개발자 서버로는 원본 의료 데이터를 전송하지 않으며, 동의하신 경우에 한해 환경 점수 개인화를 위해 격자 수준 대략 위치·가명 처리된 증상 지표만 추론 서버로 전송·처리됩니다(정밀 좌표·이름·이메일·정확한 약 이름 제외).
  • 서버에 보관(개발자 보유): 회원가입에 사용된 이메일·UID·표시 이름, 결제 정보(Google Play 영수증·구독 만료일), 동의 시에만 전송되는 익명 통계(시·도 단위 환경 정보와 비식별 증상 강도 구간)입니다.
  • 카카오 계정으로 가입하신 경우, 위 항목에 더해 다음이 서버에 보관됩니다.
    • 카카오 회원번호: 회원 식별용 UID가 'kakao:회원번호' 형태로 만들어져 계정이 유지되는 동안 보관됩니다.
    • 카카오 닉네임: 회원 표시 이름으로 사용하며 30자까지 저장됩니다. 닉네임이 없는 경우 '사용자'로 저장됩니다.
    • 카카오계정 이메일: 카카오가 인증한 이메일만 저장합니다. 이메일이 없거나 인증되지 않은 계정은 이메일을 저장하지 않습니다.
    • 프로필 사진·생일·연령대·성별은 수집하지 않습니다. 로그인 과정에서 발급되는 카카오 액세스 토큰은 회원 정보를 한 번 조회하는 데에만 사용하고 보관하지 않습니다.
  • 로그인 처리용 임시 기록: 로그인 절차를 안전하게 잇기 위한 기록이 서버에 잠시 저장됩니다. 로그인 시작 기록(유효기간 5분, 회원 식별자 없음)은 로그인이 정상적으로 끝나면 즉시 삭제되고, 로그인 완료 기록(유효기간 60초, 회원 식별용 UID 포함)은 한 번 사용하면 곧바로 무효 처리되어 다시 사용할 수 없습니다. 두 기록 모두 증상·복약 등 건강 관련 정보는 담지 않습니다.
  • 기기에 저장되는 로그인 정보: 로그인 상태를 유지하기 위해 계정 식별자·이메일·표시 이름이 사용하시는 기기에도 저장됩니다. 로그아웃하거나 앱을 삭제하면 함께 지워집니다.

1. 데이터 삭제 방법

저장 위치에 따라 두 가지 방식 중 선택하실 수 있습니다.

1) 디바이스 내 의료/생활 데이터

  • 앱 내 데이터 초기화: 앱 → 마이페이지 → 데이터 초기화 메뉴에서 즉시 영구 삭제가 가능합니다.
  • 앱 삭제(Uninstall): 스마트폰 설정에서 앱을 제거하시면 디바이스 내 모든 데이터가 자동으로 함께 삭제됩니다.
  • 로그아웃 시 자동 삭제: 로그아웃을 누르시면 다음 사용자가 같은 기기에서 로그인할 때 노출되지 않도록 기기 내 모든 로컬 데이터(IndexedDB store 및 localStorage 기록)가 자동으로 비워집니다(보안 강화).

2) 서버에 저장된 계정 정보 (이메일·UID·표시 이름·결제 정보)

  • 앱 내 회원 탈퇴: 앱 → 마이페이지 → 회원 탈퇴 메뉴에서 처리하면 Firebase 계정과 연관된 모든 식별 정보가 즉시 삭제됩니다.
    • 카카오 계정으로 가입하신 경우, 계정을 삭제하기 전에 서버가 카카오에 연결 해제를 함께 요청합니다. 카카오에서 따로 연결을 끊지 않으셔도 됩니다.
    • 이때 카카오로 전달되는 정보는 카카오 회원번호뿐이며, 증상·복약 등 건강 관련 기록은 카카오로 전송되지 않습니다.
    • 연결 해제 요청이 실패하더라도 회원 탈퇴는 그대로 진행됩니다(탈퇴가 막히지 않도록 한 조치입니다). 이 경우 드물게 카카오 쪽에 연결 표시가 남을 수 있으며, 카카오계정 설정에서 직접 연결을 끊으시거나 아래 이메일로 알려주시면 정리해 드립니다.
  • 카카오계정 설정에서 직접 연결 끊기: 카카오계정 → 연결된 서비스에서 '숨쉬다' 연결을 끊으시면, 카카오가 보내는 연결 해제 알림을 받아 서버의 회원 계정이 즉시 삭제됩니다.
    • 이 경우 서버에 저장된 회원 계정이 삭제되며, 이전 계정의 정보는 복구되지 않습니다. 같은 카카오 계정으로 다시 이용하시려면 새로 회원가입을 진행해 주세요. 기존 계정을 그대로 유지하고 싶으시다면 연결 해제 대신 앱에서 로그아웃을 이용하시는 방법을 권장합니다.
    • 이 방법은 서버의 회원 계정만 삭제합니다. 사용하시던 기기에 남아 있는 기록은 앱 → 마이페이지 → 데이터 초기화 또는 앱 삭제로 별도 정리해 주세요.
  • 이메일 요청: 앱에 접근할 수 없는 경우 insightbuild@daum.net으로 아래 양식으로 요청해 주시기 바랍니다.
    • 제목: [숨쉬다] 데이터 삭제 요청
    • 본문: 가입 시 사용한 이메일 주소, Google 계정, 또는 카카오 계정(카카오 로그인에 사용하신 카카오계정 이메일) 중 해당하는 항목을 명시
    • 카카오계정에 이메일이 없거나 인증되지 않아 저장된 이메일이 없는 경우에는, 카카오계정 → 연결된 서비스에서 '숨쉬다' 연결을 끊으시면 서버의 회원 계정이 즉시 삭제됩니다(위 안내 참고).

2. 데이터 삭제 처리 기간 및 범위

  • 처리 기간: 앱 내 메뉴로 진행 시 즉시 처리됩니다. 카카오계정 설정에서 직접 연결을 끊으신 경우에도 카카오의 연결 해제 알림이 도착하는 즉시 처리됩니다. 이메일 요청의 경우 접수일로부터 최대 7영업일 이내에 처리됩니다. 연결 해제 알림이 도착하지 않거나 처리가 실패한 경우에는 이메일로 요청해 주시면 같은 기준(최대 7영업일 이내)으로 처리해 드립니다.
  • 삭제되는 데이터:
    • Firebase Authentication 계정 정보 (이메일·UID·표시 이름)
    • 카카오 계정 정보 — UID에 포함된 카카오 회원번호와 표시 이름으로 저장된 카카오 닉네임이 계정과 함께 삭제됩니다. 앱 내 탈퇴 시에는 카카오에 연결 해제도 함께 요청합니다.
    • Firebase Custom Claims (구독 상태 등)
    • Firebase Analytics 이벤트 로그(자동 만료 처리)
    • 디바이스 내 IndexedDB의 모든 의료/생활 기록
  • 익명 통계 데이터: 동의 시 수집된 익명 통계 데이터는 본인 식별이 원천적으로 불가능한 형태로 보관되므로 개별 삭제 대상에 해당하지 않으며, 서비스 종료 시 일괄 폐기됩니다.
  • 보관·백업: 삭제 이후 회원 정보를 별도로 보관하거나 백업하지 않습니다(법령상 보존 의무가 있는 결제 영수증 등은 예외). 다만 아래 두 가지는 계정 삭제와 동시에 지워지지 않습니다.
    • 로그인 처리용 임시 기록: 한 번 사용하면 무효 처리되어 다시 로그인에 사용할 수 없지만, 회원 식별용 UID가 담긴 기록 자체는 계정 삭제 시 함께 삭제되지 않습니다.
    • 서버 운영 기록(로그): 장애 대응과 보안을 위해 로그인·탈퇴 처리 기록이 남습니다. 일부 운영 기록에는 회원 식별자나 이메일이 포함될 수 있으며, 클라우드 서비스의 로그 보존 정책에 따라 보관 기간이 지나면 삭제됩니다.
    두 기록 모두 증상·복약 등 건강 관련 정보는 포함하지 않습니다. 즉시 삭제를 원하시면 위 이메일로 요청해 주세요.

3. 관련 안내

본 앱은 의료기기가 아니며, 앱이 제공하는 모든 정보는 참고용입니다. 자세한 내용은 개인정보처리방침 및 이용약관을 참고해 주세요.
